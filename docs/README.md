# Документация проекта geometric_lib

## Общее описание решения

`geometric_lib` — библиотека на Python для вычисления площади и периметра плоских геометрических фигур. Каждая фигура вынесена в отдельный модуль, благодаря чему библиотеку можно легко расширять: чтобы добавить новую фигуру, достаточно создать файл `имя_фигуры.py` с функциями `area` и `perimeter` внутри.

Структура проекта:

| Файл | Назначение |
| --- | --- |
| `circle.py` | площадь и длину окружности круга |
| `square.py` | площадь и периметр квадрата |
| `rectangle.py` | площадь и периметр прямоугольника |
| `triangle.py` | площадь и периметр треугольника |
| `tests/test_circle.py` | unit-тесты для модуля `circle.py` (33 теста) |
| `tests/test_square.py` | unit-тесты для модуля `square.py` (33 теста) |
| `tests/test_rectangle.py` | unit-тесты для модуля `rectangle.py` (33 теста) |
| `tests/test_triangle.py` | unit-тесты для модуля `triangle.py` (33 теста) |

## Описание функций с примерами вызова

### `circle.py`

`area(r)` — площадь круга радиусом `r`. Формула: $S = \pi r^2$.

~~~python
from circle import area
area(3)
# 28.274333882308138
~~~

`perimeter(r)` — длина окружности радиусом `r`. Формула: $P = 2\pi r$.

~~~python
from circle import perimeter
perimeter(3)
# 18.84955592153876
~~~

### `square.py`

`area(a)` — площадь квадрата со стороной `a`. Формула: $S = a^2$.

~~~python
from square import area
area(4)
# 16
~~~

`perimeter(a)` — периметр квадрата со стороной `a`. Формула: $P = 4a$.

~~~python
from square import perimeter
perimeter(4)
# 16
~~~

### `rectangle.py`

`area(a, b)` — площадь прямоугольника со сторонами `a` и `b`. Формула: $S = ab$.

~~~python
from rectangle import area
area(4, 5)
# 20
~~~

`perimeter(a, b)` — периметр прямоугольника со сторонами `a` и `b`. Формула: $P = 2(a + b)$.

~~~python
from rectangle import perimeter
perimeter(4, 5)
# 18
~~~

### `triangle.py`

`area(a, h)` — площадь треугольника с основанием `a` и высотой `h`. Формула: $S = \frac{a \cdot h}{2}$.

~~~python
from triangle import area
area(6, 4)
# 12.0
~~~

`perimeter(a, b, c)` — периметр треугольника со сторонами `a`, `b`, `c`. Формула: $P = a + b + c$.

~~~python
from triangle import perimeter
perimeter(3, 4, 5)
# 12
~~~

## Тестирование

Для проверки корректности работы всех функций библиотеки написан набор из 132 автоматических unit-тестов на основе стандартного фреймворка `unittest` (директория `tests/`). Тесты охватывают позитивные сценарии (целые, дробные, малые и большие числа), граничные значения (нулевые аргументы), математические свойства (масштабирование, коммутативность), а также негативные сценарии (отрицательные значения, нарушение неравенства треугольника, `inf`/`nan`, некорректные типы данных и арность).

Команда запуска всех тестов из корня проекта:

~~~bash
python -m unittest discover -s tests -v
~~~
